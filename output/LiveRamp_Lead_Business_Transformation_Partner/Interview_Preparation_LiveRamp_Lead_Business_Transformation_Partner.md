### Tech Q3: "In AI FinOps, how do you prevent agentic workflows and LLM applications from spiraling out of control in terms of inference costs and latency?"
- **Candidate Framework (Anchored in AI Stack Optimization Credential):**
  1. **Prompt Caching & Prefix Optimization:** Structure prompts so that static system instructions, regulatory context, and API tool schemas appear in the first prefix tokens. Modern LLM providers (Anthropic, OpenAI, Google) cache repeated prefixes at up to 90% discount and 80% latency reduction.
  2. **Model Right-Sizing (Cascading Architecture):** Never use a frontier model ($30/M tokens) when a small language model (SLM) or fine-tuned model ($0.20/M tokens) suffices.
     - *Tier 1 (SLM / Regex):* Document classification, entity extraction, data cleansing.
     - *Tier 2 (Mid-Tier Model):* Standard query generation, schema translation.
     - *Tier 3 (Frontier Model):* Complex edge-case synthesis, multi-step strategic planning.
  3. **Loop Capping & Recursion Guards:** Implement strict recursion bounds (`max_iterations = 5`) in all LangGraph state machines, paired with cumulative token budgets per execution run. If an agent loops repeatedly without state progression, break execution and escalate to human review.
  4. **Context Compaction:** Periodically summarize and compact conversation history rather than appending endless raw transcripts into the context window.
